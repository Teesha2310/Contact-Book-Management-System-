# Contact Book Management System

A C++ based Contact Book Management System that allows users to add, search, update, and delete contacts using Object-Oriented Programming and File Handling concepts.

## Features

✅ Add New Contact

✅ Display All Contacts

✅ Search Contact by Name

✅ Update Contact Details

✅ Delete Contact

✅ File Handling for Permanent Storage

✅ Menu-Driven Interface

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- File Handling
- Functions

## Concepts Implemented

- Classes and Objects
- CRUD Operations
- Searching
- File Handling
- Data Management
